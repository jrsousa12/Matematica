# Matemática

Projeto piloto de recomposição de aprendizagem em Matemática para o 9º ano.

- [App do aluno](app-matematica-9ano/): missão diária de 5 questões, lições e progresso. Funciona sem internet depois do primeiro acesso.
- [Painel do professor](painel-professor-9ano/): importa os arquivos exportados pelos alunos e mostra o acompanhamento da turma.
